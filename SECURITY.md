# Security policy

Please report security issues privately to **support@dankmachine.com** with "security" in the subject. Do not open a public issue.

We aim to reply within 3 business days and to ship a fix or mitigation within 14 days for confirmed issues.

Scope: the `dank-meme-sounds` npm package (stdio MCP server and `play` CLI) and the hosted MCP endpoint at https://dankmachine.com/mcp.
