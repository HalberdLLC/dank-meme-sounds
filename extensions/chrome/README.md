# DankMachine Meme Sounds (Chrome / Edge extension)

38k meme sound buttons in your toolbar.

- **Popup:** trending sounds, search as you type, or describe a moment ("my code finally compiled") for fitting reaction sounds. ▶ plays, 🔗 copies the sound page link.
- **Right-click selected text** → "Find a meme sound for …" opens the popup with that text.

Uses the free public API at `https://dankmachine.com/api/v1` (no key, no tracking). Permissions: `contextMenus`, `storage` (session only) and the dankmachine.com host.

## Load unpacked (development)

1. `chrome://extensions` (or `edge://extensions`), turn on Developer mode.
2. Load unpacked → pick this folder.

## Publish

Zip the folder contents (`dankmachine-chrome-0.1.0.zip` in Releases) and upload it in the Chrome Web Store developer dashboard / Edge Add-ons partner center.
